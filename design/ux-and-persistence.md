# Design: UX and persistence

_从主菜单到结算的界面流程，以及最高分/设置的本地存档。负责人：game-designer（流程）、tech-director（存档格式）。_

Serves pillar: **再来一局的干净循环**。

## Goals

- 玩家从启动到第一局开始不超过 3 秒、不超过 3 次确认。
- 每局结束后，重开保持在一次确认内，最高分和本局分数同屏可见。
- 设置、最高分和局数跨启动保留；存档损坏时游戏仍能启动并给出可见提示。

## Player experience

主菜单只有标题、三个主按钮和一行页脚（版本号与制作人员/许可入口），默认焦点在“开始游戏”。模式选择页三张横卡，卡上直接写规则和最高分，不再进入二级说明。进入游戏后 HUD 只占四角；暂停菜单盖住场地但不遮住当前分数；结算页先显示“新纪录！”再显示重开按钮，玩家按一次确认就能再来一局。

## Rules

### Screens

1. 流程：`Boot → Main menu → Mode select → Countdown → Playing ⇄ Paused → End panel`；Settings 可从主菜单和暂停菜单进入，返回原处。
2. 主菜单：标题、`开始游戏`（默认焦点）、`设置`、`退出`；页脚显示版本号与“制作人员/许可”入口。
3. 模式选择：三张卡（Classic / Maze / Time Attack），显示模式名、一句规则、该模式最高分；不可用场地卡显示“场地数据错误”并禁用；`返回` 回主菜单。
4. HUD：左上分数、其下长度与速度（1 位小数），右上最高分，顶部中央模式名（Time Attack 显示剩余秒数），右下暂停提示；数值用信号更新，不轮询。
5. 暂停：`Esc` / 手柄 `Start` / 触屏右上按钮打开；选项 `继续`（默认焦点）、`重新开始`、`模式选择`、`设置`、`回主菜单`；暂停冻结逻辑与计时。
6. 结算：显示结束原因（撞墙/撞障碍/撞自己/时间到/清场）、本局分数、最高分、是否新纪录，按钮 `再来一局`（默认焦点）、`换模式`、`主菜单`；出现后 0.4 秒内忽略确认输入。
7. 设置：主音量、音效音量、语言（简体中文/English）、相机（固定/跟随）、色盲模式、减少动态、触屏方向键（自动/开/关）、字号（100%/125%/150%）；相机改动下一局生效，其余立即生效。
8. 本地化：所有玩家可见文字走翻译键（`tr()`），场景与脚本不内联字符串；1.0 提供 `zh_CN` 与 `en`，缺失键回退英文。
9. 导航：键鼠、手柄、触屏都能完成全部流程；最后使用的输入设备决定按钮提示图标；焦点顺序显式，焦点状态可见，交互目标至少 44×44 px。
10. 失焦自动暂停：桌面端窗口失去焦点 0.5 秒后自动暂停；恢复焦点不自动继续，等玩家确认倒计时。

### Persistence

11. 存档路径 `user://save.json`，UTF-8、无 BOM、键排序稳定；`schema_version` 当前为 1。
12. 存字段：每模式最高分、总对局数、全部设置；不存当前局状态、不存随机种子、不存任何个人信息。
13. 读取顺序：`save.json` → 失败则 `save.bak` → 都失败则默认值；损坏文件重命名为 `save.corrupt-<unix>.json` 保留，不静默删除。
14. `schema_version` 高于当前版本：以只读方式加载可识别字段并使用默认设置，本次运行不覆盖存档，避免旧版本破坏新档。
15. 写入：先写 `save.tmp`，`flush()` 后替换 `save.json`，替换前把旧文件复制为 `save.bak`；任一步失败保留内存状态并显示一次非阻塞提示。
16. 写入时机：新最高分、运行结束、设置变更（防抖 0.5 秒）、对局开始（局数 +1）、正常退出；不每帧写盘。
17. 最高分按模式独立；分数相等不算新纪录；局数在开局时 +1，即使中途退出也计入。
18. 默认设置：主音量 80%、音效 80%、语言跟随系统（非中文则英文）、相机固定、色盲关、减少动态关、触屏自动、字号 100%。

## Save schema

```json
{
  "schema_version": 1,
  "best_scores": { "classic": 120, "maze": 80, "time_attack": 150 },
  "total_runs": 42,
  "settings": {
    "master_volume": 0.8,
    "sfx_volume": 0.8,
    "language": "zh_CN",
    "camera_mode": "fixed",
    "colorblind": false,
    "reduce_motion": false,
    "touch_controls": "auto",
    "font_scale": 1.0
  }
}
```

## Numbers and tuning

| Value | Default | Range | Unit | Tuned in |
|---|---|---|---|---|
| 存档 schema | 1 | 1 | version | 存档模块 |
| 写盘防抖 | 0.5 | 0.1–2.0 | seconds | 设置控制器 |
| 结算输入锁 | 0.4 | 0–1.0 | seconds | 结算面板 |
| 失焦自动暂停延迟 | 0.5 | 0–2.0 | seconds | 游戏控制器 |
| 主音量默认 | 80 | 0–100 | percent | 设置 |
| 音效音量默认 | 80 | 0–100 | percent | 设置 |
| 字号档位 | 100/125/150 | 100–150 | percent | 设置 |
| 交互目标最小尺寸 | 44×44 | ≥44 | px | UI 主题 |
| 面板过渡 | 0.15 | 0.05–0.30 | seconds | UI 主题 |
| 存档体积上限 | 16 | ≤16 | KB | 存档模块 |
| 局数上限 | 999999 | 0–999999 | runs | 存档模块（防止无限增长） |

_表中默认值为提案；见 Open questions。_

## Edge cases

- 存档写入时断电：`save.json` 仍是上一个完整版本；下次读取成功，`save.tmp` 被忽略并删除。
- 两个实例同时运行：后退出者覆盖先退出者；1.0 接受为已知限制，不实现文件锁。
- 语言键缺失：回退英文并在日志记录一次，不显示原始键。
- 设置值越界（手改 JSON）：夹到合法范围并写回一次。
- `total_runs` 达到上限：保持 999999，不再增加。
- 暂停中打开设置再返回：回到暂停菜单，不自动继续。
- 结算时按“换模式”：不保留本局分数，但最高分已写入。
- 触屏设备同时有键盘：以最后输入设备显示提示，不锁定输入方式。
- 存档目录不可写：游戏可玩一局，设置与最高分只存在内存，退出时提示一次。

## Open questions

- 1.0 的语言只做简体中文与英文是否足够，还是需要日文；负责人：producer。
- 中文字体用系统字体（`SystemFont`，不增加包体）还是内置开源字体（跨平台一致）；负责人：technical-artist。
- 是否需要键位重映射；issue 未要求，提案 1.0 不做；负责人：game-designer。
