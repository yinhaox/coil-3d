## Highlights

- 等距 3D 场地：网格、四面墙、蛇头与身体可区分、黄色食物；`Q`/`E` 转 90°、滚轮缩放，整场始终在画面内 (#8, @nightjar-agent)
- 经典蛇规则：网格移动、不能 180° 反向、吃到食物 +10 分且变长、速度从 8.0 升到 16.0 cells/s 上限、撞墙/障碍/自己结束 (#6, #16, @nightjar-agent)
- 转向在按键当帧被接受并起转（0.10 秒补间），逻辑步进节拍不变 (#14, @nightjar-agent)
- 主菜单（Play / How to play / Settings / Quit）与键盘焦点，How to play 页 (#25, #27, @nightjar-agent)
- 一局内 HUD（Score / Length / Speed / Time / Best）、`Esc` 暂停（Resume / Restart / Main menu / Settings）、结束面板（Retry / Main menu，破纪录显示 New best）(#25, @nightjar-agent)
- 最佳成绩与主/SFX 音量、静音写入 `user://save.json`，重启后保留 (#25, #27, @nightjar-agent)
- 运行时合成音效：转向、吃、加速、撞墙与按钮点击，无音频文件 (#27, @nightjar-agent)
- 4 个场地数据（classic-12、classic-16、maze-01、time-attack-16）；本版只有 Classic 有入口 (#6, #8, @nightjar-agent)

## Known issues

- 只有 Classic 可玩：Maze / Time Attack 的场地数据与 headless 规则已就绪，但菜单没有入口（`design/game-modes.md` 仍为 in review）。
- 无本地化：界面只有英文文案，没有 zh_CN / en 切换；`design/release.md` 第 13 条的双语目标未实现。
- 手柄与触屏未实现、未验证；`design/accessibility.md` 的触控方案 (#5) 只是设计。
- 音效是运行时合成的占位级：5 个 cue（turn / eat / speed_up / crash / ui_click），无背景音乐，未做总线调优（`design/release.md` 第 14 条）。
- 无商店素材、无代码签名：仓库有 `LICENSE` 与 `LICENSES.md`，但没有图标、封面、商店截图与平台签名配置。
- 三个导出预设（Windows Desktop / Linux / Web，见 `export_presets.cfg`）只在 Windows 上实测过；macOS 预设未加，`design/release.md` 第 3 条的三平台要求未满足。
- 三平台导出与 Windows 包启动截图（28,269 字节）来自 issue #28 的已核对事实，产物不在仓库内；本 ticket 没有、也不允许复跑导出。
